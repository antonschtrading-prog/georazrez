# Открытые компоненты

Платные библиотеки, CAD-ядра, внешние API и облачные сервисы не используются.

| Компонент | Назначение | Лицензия |
|---|---|---|
| React | Интерфейс | MIT |
| Vite | Сборка | MIT |
| Tailwind CSS | Стили | MIT |
| Radix UI | Доступные диалоги и меню | MIT |
| ExcelJS | Локальное чтение и формирование XLSX | MIT |
| Lucide | SVG-иконки | ISC |
| IBM Plex Sans / IBM Plex Mono | Интерфейс и числовые данные | SIL OFL 1.1 |

Исходные DXF и XLSX, а также демонстрационная модель проекта предоставлены пользователем. Геологические алгоритмы основаны на подготовленном в ходе аудита исправленном модуле извлечения DXF.
